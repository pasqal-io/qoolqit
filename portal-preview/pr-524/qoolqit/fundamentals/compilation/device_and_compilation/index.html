Special compilation: maximum allowed duration

Section titled “Special compilation: maximum allowed duration”

Whenever possible, QoolQit compilation directly maps the input quantum program to hardware instructions while preserving energy-to-time ratios (see compilation rationale). In some applications, however, it is advantageous to decouple time from compilation. For example, in adiabatic protocols, users may wish to set the program duration independently, such as using the longest duration supported by the hardware.

Warning

Programs compiled with the flag device_max_duration_ratio are not portable across different devices.

To do so, set the corresponding flag at compilation:

As anticipated, this flag will decouple time from the compilation, letting the user set a time relative to the maximum allowed by the selected device. Moreover, as a drive's amplitude/detuning can be composed by many waveforms, this feature will rescale them preserving their relative durations.
